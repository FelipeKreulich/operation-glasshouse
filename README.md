# Operation GLASSHOUSE

Red team C2 infrastructure with evasion techniques, paired with a self-detection blue team pipeline — offense and defense in one closed-lab project.

> ⚠️ Research project running in a closed, isolated lab environment. All traffic, payloads, and infrastructure operate exclusively against owned systems — no third-party networks or targets involved.

## Overview

This project documents a full cycle of offensive operation (evasive C2) and defensive detection (catching the C2's own traffic), running entirely in an isolated environment.
